# T-010 Команда split

> **Что:** разбить эпик на фичи или фичу на задачи с зависимостями между ними.
> **Зачем:** декомпозиция MVP — основная работа при старте проекта.
> **Готово, когда:** из описания эпика получается набор фич и задач без циклов, каждая задача размером не больше L.

## Критерии готовности

- [ ] Предлагает разбиение списком (ID, «Коротко», роль, зависимости) до записи файлов
- [ ] Для рискованных решений предлагает пару research → impl
- [ ] Учитывает задачи, которые уже есть, не создаёт дублей
- [ ] Пишет файлы после подтверждения, прогоняет проверку, обновляет доску
