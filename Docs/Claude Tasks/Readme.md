# План задач

Эта папка — план проекта в формате плагина **claude-tasks** (`/task:*`). Открывается в Obsidian как обычное хранилище, без плагинов.

- [[Board]] — доска: что готово к работе, что в работе, что заблокировано.
- `Epics/` → `Features/` → `Tasks/` — план; `Backlog/` — идеи; `Adr/` — принятые решения.
- Формат и правила ведения задач — скил `task:format` плагина (`plugin/skills/format/SKILL.md`).

**Главное правило для агентов:** взял задачу — поставь `in-progress` и запиши в «Журнал»; закончил — отметь критерии, поставь `done`/`review` и запиши итог. Статус и журнал обновляются сразу, а не потом.
