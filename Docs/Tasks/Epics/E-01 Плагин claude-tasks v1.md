# E-01 Плагин claude-tasks v1

> **Что:** плагин для Claude Code, который ведёт в любом проекте план задач в `Docs/Tasks/` — эпики, фичи, задачи, бэклог идей и граф зависимостей.
> **Зачем:** один раз разложить проект на задачи, а дальше давать агентам задачи командами (`next`, `create`, `done`) и корректировать план по ходу работы.
> **Готово, когда:** плагин ставится в любой проект, `/task:help`, `init`, `create`, `split`, `next`, `done`, `replan`, `idea`, `board` работают, план читается в Obsidian без сторонних плагинов.

## Цель

Система, которой одинаково удобно пользоваться человеку и агентам любой роли (геймдизайнер, архитектор, программист, девопс):

- задачу можно открыть и за несколько секунд понять, о чём она (блок «Коротко»);
- подробности — любого объёма ниже, не мешают быстрому чтению;
- зависимости хранятся в одном месте (`depends_on` задачи), всё остальное генерируется;
- план живой: после каждой закрытой задачи будущие задачи можно пересмотреть.

## MVP

- Формат задач + шаблоны + правила работы агента с планом.
- Каркас плагина, устанавливаемый локально.
- Скрипт проверки графа и генерации доски.
- Команды `/task:…`: help, init, create, split, next, done, replan, idea, board.
- Проверка на живом тестовом проекте.

## После MVP

Идеи — в бэклоге (`Docs/Tasks/Backlog/`).

## Фичи

Список фич не дублируется здесь — он собирается из поля `parent` фич и показывается в [[Board]].
