# F10-01 Журнал в идее при закрытии

> **Что:** при закрытии идеи по совету `/task:create` (`set <I-ID> done --promoted-to … --log …`) скрипт дописывает в идею раздел «Журнал», которого у идей быть не должно.
> **Зачем:** идеи выглядят по-разному (I-002 — строка «Взята в план», I-005 — журнал), спецификация нарушается молча, а `check` этого не видит.
> **Готово, когда:** закрытие идеи само пишет строку `**Взята в план:** [[…]] (дата).`, `--log` для типов без журнала отклоняется, `check` предупреждает о журнале в идее или ADR.

## Воспроизведение

1. Идея `I-005` в статусе `idea`, есть фича `F-09`.
2. `tasks.mjs set I-005 done --promoted-to F-09 --log "взята в план: фича F-09 эпика E-02."` — так велит `plugin/skills/create/SKILL.md:24`.
3. В конце файла идеи появился раздел `## Журнал` с записью; `tasks.mjs check` — «ошибок 0, предупреждений 0».

**Ожидалось:** у идеи нет журнала (спецификация, раздел 7: idea — только «Коротко»); отметка о переносе — строка `**Взята в план:** [[F-09 …]] (2026-10-13).`, как у I-002.

## Критерии готовности

- [x] `set <I-ID> done --promoted-to <ID>` дописывает в идею строку `**Взята в план:** [[<имя>]] (<дата>).`; при повторном вызове строка заменяется, а не дублируется
- [x] `set` с `--log` для типа без журнала (idea, adr) отклоняется с понятным сообщением, файл не меняется
- [x] `check` предупреждает (`log-not-allowed`) о разделе «## Журнал» в идее или ADR
- [x] Скил `create` больше не советует `--log` при закрытии идеи; спецификация (`format`) описывает строку «Взята в план» и что её пишет скрипт
- [x] На каждый пункт — тест; все тесты плагина зелёные; `check` плана репозитория и примера — без ошибок
- [x] Версия плагина поднята

## Детали

- Код — `setStatus` и проверки тела в `check` (`plugin/scripts/tasks.mjs`); признак «у типа есть журнал» — уже есть: `TYPES[type].journal`. Его же использовать и для отказа `--log`, и для предупреждения — одно место.
- Предупреждение, а не ошибка: планы, которые вели по старому совету скила, не должны стать «сломанными».
- Отказ `--log` у idea/adr: причину отмены идеи пишут в её тексте правкой файла.

## Проверка

1. `node --test plugin/scripts/test/*.test.mjs` — зелёные, среди них новые тесты.
2. Во временном плане: `set I-001 done --promoted-to F01-01` → в идее строка «Взята в план», нет «## Журнал»; с `--log` → отказ.
3. `node plugin/scripts/tasks.mjs check` в корне и в `examples/guess-number` — без ошибок и предупреждений.
