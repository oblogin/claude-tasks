# F-09 Строгие переходы статусов

> **Что:** скрипт плагина пропускает только переходы статусов из спецификации; остальное — с `--force` и пометкой в журнале.
> **Зачем:** агент не сможет незаметно закрыть задачу, минуя работу, или увести статус в бессмысленное состояние.
> **Готово, когда:** `set` проверяет переходы для всех типов, законные сценарии команд `/task:*` проходят без `--force`, спецификация и README описывают правило.

## Входит

- Проверка переходов в `tasks.mjs set`, сообщения об отказе, `--force` с пометкой в журнале — [[F09-01 Проверка переходов в set]].
- Обновление спецификации, README и скилов под новое правило.

## Не входит

- Проверка истории статусов по журналу в `check`.
- Права ролей на переходы (кто может ставить `done`).

## Принятые решения

- Обход — только `--force`, без отдельного флага: он уже значит «я понимаю, что нарушаю правило».
