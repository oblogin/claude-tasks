# T-013 Команды idea и board

> **Что:** `idea` — быстро записать идею в бэклог; `board` — проверить граф и пересобрать доску.
> **Зачем:** идеи не должны теряться и не должны мешать плану; доска должна быть актуальной одной командой.
> **Готово, когда:** идея записывается в одну фразу без диалога, а `board` показывает сводку и ошибки графа.

## Критерии готовности

- [ ] `idea <текст>` создаёт `I-xxx` в `Backlog/` без лишних вопросов
- [ ] Идею можно превратить в задачу/фичу (через `create`), в идее остаётся ссылка на результат
- [ ] `board` прогоняет проверку, пересобирает `Board.md` и выводит короткую сводку в чат
