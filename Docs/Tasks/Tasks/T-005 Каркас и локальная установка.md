# T-005 Каркас и локальная установка

> **Что:** создать манифест и структуру папок плагина по ADR-001 и установить его в тестовый проект.
> **Зачем:** каркас, в который F-03 и F-04 добавляют скрипт и команды.
> **Готово, когда:** плагин `task` установлен из локального маркетплейса, и заглушка `/task:help` отвечает в тестовом проекте.

## Критерии готовности

- [ ] Структура по [[ADR-001 Устройство плагина]]: `.claude-plugin/marketplace.json` в корне репозитория, плагин в `plugin/` с `plugin/.claude-plugin/plugin.json` (`name: "task"`)
- [ ] Заглушка скила `plugin/skills/help/SKILL.md`
- [ ] `claude plugin validate` проходит без ошибок
- [ ] Установка: `claude plugin marketplace add C:\AI\claude-tasks` → `claude plugin install task@claude-tasks`; `/task:help` отвечает
- [ ] `.gitattributes` с `* text=auto eol=lf` (сейчас git ругается на LF/CRLF)
- [ ] Инструкция установки — в README (черновик, финал в T-015)

## Детали

Закрыть непроверенные пункты ADR-001 и записать результат в журнал (при расхождении — поправить ADR):

1. Работает ли вызов без префикса (`/help` vs `/task:help`).
2. Корректен ли `source: "./plugin"` в `marketplace.json` для локального маркетплейса на Windows.
3. Как десктоп-приложение показывает команды плагина в меню `/`.

## Проверка

1. Установить плагин, открыть тестовую папку, вызвать `/task:help` — заглушка отвечает.
2. Поправить текст заглушки, `/reload-plugins` — изменения видны без переустановки.
