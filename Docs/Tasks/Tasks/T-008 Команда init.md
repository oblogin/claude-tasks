# T-008 Команда init

> **Что:** команда создаёт в проекте `Docs/Tasks/` со структурой папок, шаблонами и пустой доской.
> **Зачем:** первый шаг для любого нового проекта.
> **Готово, когда:** в пустом проекте после `init` можно сразу вызвать `create`.

## Критерии готовности

- [ ] Создаются папки, шаблоны, `Board.md`, короткий `Readme.md` в `Docs/Tasks/` со ссылкой на формат
- [ ] Добавляет в `CLAUDE.md` проекта короткий блок «Работа с задачами»: где план, как брать задачу, обязанность обновлять статус и журнал — так правило видят все агенты проекта, даже без вызова команд
- [ ] Предлагает (с подтверждения) рекомендуемые настройки Obsidian для хранилища `Docs/Tasks/`, проверенные на этом репозитории:
  - `app.json`: `"propertiesInDocument": "hidden"`, `"showInlineTitle": false` — задача открывается сразу с «Коротко»;
  - `graph.json`: фильтр `-file:Board -file:Readme`, `"showArrow": true`, цвета по папкам (Epics — красный, Features — оранжевый, `Tasks/` — синий, Adr — зелёный, Backlog — серый; пути считаются от корня хранилища);
  - настройки пишутся, только когда Obsidian закрыт — иначе он перезапишет их при выходе
- [ ] Предлагает добавить `Docs/Tasks/.obsidian/` в `.gitignore` — личные настройки Obsidian не должны попадать в репозиторий (в этом репозитории так уже случилось)
- [ ] Повторный `init` ничего не ломает и не перезаписывает существующие задачи
