# T-011 Команды next и done

> **Что:** `next` находит следующую готовую задачу и берёт её в работу; `done` закрывает задачу и записывает итог.
> **Зачем:** основной рабочий цикл: «возьми следующую» → работа → «закрой».
> **Готово, когда:** цикл next → done проходит на тестовом проекте, статусы и журнал обновляются сами.

## Критерии готовности

- [ ] `next` берёт кандидатов у скрипта, показывает «Коротко» выбранной и 1–2 альтернативы, ставит `in-progress`
- [ ] `next <ID>` берёт конкретную задачу; если зависимости не закрыты — предупреждает
- [ ] `next --role <роль>` фильтрует по роли
- [ ] `done` сверяет критерии готовности; невыполненные пункты — явно, с причиной
- [ ] `done` пишет запись в «Журнал», ставит `done` (или `review`) и обновляет доску
- [ ] `done` показывает задачи, которые разблокировались, и спрашивает, нужен ли `replan`
