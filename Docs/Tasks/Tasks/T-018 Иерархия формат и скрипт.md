# T-018 Иерархия формат и скрипт

> **Что:** перевести формат и скрипт на вложенные папки и ID задач внутри фичи.
> **Зачем:** на этом держатся все команды; без него перевод плана невозможен.
> **Готово, когда:** спецификация описывает иерархию, скрипт (check, board, next, new, init, hook) работает с ней, тесты зелёные.

## Критерии готовности

- [ ] Спецификация: раскладка, ID (`E-01`, `F-01`, `F01-07`), папка = имя заметки, правила переноса
- [ ] `check`: файл в папке своего родителя, ID задачи совпадает с номером фичи, формат ID
- [ ] `new` создаёт эпик/фичу/задачу в нужной папке с ID внутри фичи; `init` создаёт только `Backlog/` и `Adr/`
- [ ] Сортировка ID учитывает иерархию (`F02-01` после `F01-99`, `F-100` после `F-99`)
- [ ] Хуки узнают задачи по новым ID и путям
- [ ] Тесты переписаны под иерархию и зелёные
