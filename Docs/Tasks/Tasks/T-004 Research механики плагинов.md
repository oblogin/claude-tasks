# T-004 Research механики плагинов

> **Что:** выяснить, как устроены плагины Claude Code, и выбрать, из чего собирать наш (скилы, команды, агенты, скрипты).
> **Зачем:** от этого зависит, как будут называться и вызываться команды и как агенты в чужих проектах узнают о формате.
> **Готово, когда:** есть ADR `Docs/adr/ADR-001 Устройство плагина.md` с ответами на вопросы ниже.

## Критерии готовности

- [ ] Структура плагина и манифеста; как установить его локально на Windows из `C:\AI\claude-tasks`
- [ ] Скилы или команды для `next`/`create`/...: чем отличаются, как вызываются, какие получаются имена (есть ли префикс плагина)
- [ ] Как любой агент проекта (в том числе субагент) подхватывает правила формата — автоматически или по ссылке
- [ ] Какие события хуков доступны плагину и как хук возвращает сообщение агенту (для контроля статусов в T-016)
- [ ] Как из скила запускать скрипт плагина (путь к плагину, Node без зависимостей)
- [ ] Решение записано в ADR с обоснованием

## Детали

Исходные данные: Node v24 установлен, Python ставить не будем — скрипт на Node без npm-зависимостей.
