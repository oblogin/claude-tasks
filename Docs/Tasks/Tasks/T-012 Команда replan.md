# T-012 Команда replan

> **Что:** пересмотреть будущие задачи с учётом того, что выяснилось в работе.
> **Зачем:** план живой — решения из закрытой задачи часто меняют следующие.
> **Готово, когда:** после закрытия задачи агент предлагает конкретные правки зависимых задач, и они применяются только после подтверждения.

## Критерии готовности

- [ ] Область пересмотра: зависимые от задачи / фича / весь план
- [ ] Правки показываются как список «задача — что меняем — почему»
- [ ] Можно добавить, отменить (`cancelled`), разбить, переставить зависимости
- [ ] Каждое изменение отражается в «Журнале» изменённой задачи со ссылкой на причину
