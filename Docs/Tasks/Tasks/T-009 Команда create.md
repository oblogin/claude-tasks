# T-009 Команда create

> **Что:** диалоговая команда: агент расспрашивает, что нужно, и оформляет задачу (или эпик/фичу) со связями в графе.
> **Зачем:** основной способ пополнять план — через обсуждение, а не ручное заполнение шаблона.
> **Готово, когда:** из расплывчатой фразы после диалога получается задача, которую другой агент может взять без уточнений.

## Критерии готовности

- [ ] Агент задаёт вопросы по очереди, пока не ясны «Что / Зачем / Готово, когда» и роль
- [ ] Предлагает тип, родителя и зависимости, исходя из существующего плана
- [ ] Если задача слишком большая — предлагает сделать её фичей и разбить (переход в `split`)
- [ ] Показывает черновик целиком и пишет файл только после подтверждения
- [ ] После записи прогоняет проверку графа и обновляет доску
