# T-017 Команда help

> **Что:** `/task:help` рассказывает, какие команды есть, что делает каждая и с чего начать.
> **Зачем:** не нужно помнить все команды и открывать README — справка в одну команду.
> **Готово, когда:** `/task:help` показывает все команды плагина с одной строкой описания и подсказывает следующий шаг по состоянию проекта.

## Критерии готовности

- [x] Список всех команд плагина: имя, аргументы, одна строка «что делает»
- [x] Список собирается из самих скилов (их `description`/`argument-hint`), а не дублируется руками — новая команда появляется в справке сама
- [x] Подсказка по состоянию: нет `Docs/Tasks/` → «начни с `/task:init`»; есть задачи в `in-progress` → напомнить о них; есть готовые → «`/task:next`»
- [x] `/task:help <команда>` — подробнее об одной команде с примером
- [x] Коротко: вся справка помещается на один экран

## Детали

Пользователь просил `/task-help`; из-за префиксов плагинов (см. [[ADR-001 Устройство плагина]]) команда называется `/task:help`.

## Проверка

1. В проекте без `Docs/Tasks/` — справка предлагает `/task:init`.
2. Добавить временный скил — он появляется в справке без правки `help`.
