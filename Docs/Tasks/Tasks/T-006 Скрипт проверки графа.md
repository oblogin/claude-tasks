# T-006 Скрипт проверки графа

> **Что:** Node-скрипт без зависимостей: читает все файлы `Docs/Tasks/`, строит граф и сообщает об ошибках.
> **Зачем:** агенты правят план вручную — нужен детерминированный сторож, который ловит циклы и битые ссылки.
> **Готово, когда:** на намеренно сломанном плане скрипт находит каждую ошибку и возвращает ненулевой код.

## Критерии готовности

- [ ] Разбор frontmatter (подмножество YAML, которое использует формат)
- [ ] Ошибки: цикл, ссылка на несуществующий файл, дубль ID, неизвестный статус/тип, нет `parent` у задачи/фичи
- [ ] Предупреждения: пустой блок «Коротко», `ready`-задача без критериев готовности
- [ ] Предупреждения о статусах: `done` с неотмеченными критериями без пояснения; `done`/`review` без записи в «Журнале»; `in-progress` при незакрытых `depends_on`; больше одной `in-progress` задачи у одной роли
- [ ] Вывод понятен человеку и агенту; есть режим JSON для команд
- [ ] Тесты на наборе примеров (корректный и сломанные планы)

## Проверка

1. Прогнать на `Docs/Tasks/` этого репозитория — ошибок нет.
2. Прогнать на тестовых сломанных планах — каждая ошибка найдена.
