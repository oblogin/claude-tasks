# T-019 Команды move и migrate

> **Что:** `move` — перенести задачу в другую фичу или фичу в другой эпик; `migrate` — перевести плоский план в иерархию.
> **Зачем:** без них перенос и переход требуют ручной правки десятков ссылок.
> **Готово, когда:** обе команды меняют имена и все ссылки во всём плане, пишут старый ID в журнал, после них проверка чистая.

## Критерии готовности

- [ ] `move <задача> --to <F-ID>`: новый ID в целевой фиче, файл перенесён, ссылки `[[…]]` и упоминания ID обновлены во всех файлах плана, запись в журнале
- [ ] `move <F-ID> --to <E-ID>`: папка фичи перенесена, ID не меняются, `parent` обновлён
- [ ] `migrate`: эпики и фичи — в папки, задачи перенумерованы внутри фич по порядку старых ID, все ссылки и упоминания обновлены, соответствие старых и новых ID выведено
- [ ] Повторный `migrate` на уже иерархическом плане ничего не ломает
- [ ] Тесты на обе команды
