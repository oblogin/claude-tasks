## Готово

| Задача | Коротко |
|---|---|
| [[F01-01 Спецификация формата]] | написать спецификацию формата — единственный документ, по которому любой агент создаёт и ведёт задачи. |
| [[F01-02 Шаблоны файлов]] | сделать шаблоны для каждого типа: epic, feature, task, research, bug, idea, adr. |
| [[F02-01 Research механики плагинов]] | выяснить, как устроены плагины Claude Code, и выбрать, из чего собирать наш (скилы, команды, агенты, скрипты). |
| [[F02-02 Каркас и локальная установка]] | создать манифест и структуру папок плагина по ADR-001 и установить его в тестовый проект. |
| [[F03-01 Скрипт проверки графа]] | Node-скрипт без зависимостей: читает все файлы `Docs/Tasks/`, строит граф и сообщает об ошибках. |
| [[F03-02 Генерация доски и кандидатов next]] | скрипт пересобирает `Board.md` и умеет выдать список задач, готовых к работе. |
| [[F04-01 Команда init]] | команда создаёт в проекте `Docs/Tasks/` со структурой папок, шаблонами и пустой доской. |
| [[F04-02 Команда create]] | диалоговая команда: агент расспрашивает, что нужно, и оформляет задачу (или эпик/фичу) со связями в графе. |
| [[F04-03 Команда split]] | разбить эпик на фичи или фичу на задачи с зависимостями между ними. |
| [[F04-04 Команды next и done]] | `next` находит следующую готовую задачу и берёт её в работу; `done` закрывает задачу и записывает итог. |
| [[F04-05 Команда replan]] | пересмотреть будущие задачи с учётом того, что выяснилось в работе. |
| [[F04-06 Команды idea и board]] | `idea` — быстро записать идею в бэклог; `board` — проверить граф и пересобрать доску. |
| [[F04-07 Контроль статусов]] | хуки плагина, которые не дают агенту закончить работу, не обновив статус и журнал задачи. |
| [[F04-08 Команда help]] | `/task:help` рассказывает, какие команды есть, что делает каждая и с чего начать. |
| [[F05-01 Полный цикл на тестовом проекте]] | на маленькой тестовой игре пройти init → create эпика MVP → split → несколько next/done → replan → idea. |
| [[F05-02 README]] | README плагина: установка, команды, как устроен план, как подключить свою роль. |
| [[F05-03 create пишет файл до подтверждения]] | `/task:create` создаёт и заполняет файлы задачи до того, как пользователь подтвердил черновик, а сам черновик показывает сокращённой сводкой. |
| [[F05-04 Флаг create без подтверждения]] | флаг `--yes` (`-y`) у `/task:create` — задача записывается сразу, без показа черновика и вопроса «записывать?». |
| [[F06-01 Иерархия формат и скрипт]] | перевести формат и скрипт на вложенные папки и ID задач внутри фичи. |
| [[F06-02 Команды move и migrate]] | `move` — перенести задачу в другую фичу или фичу в другой эпик; `migrate` — перевести плоский план в иерархию. |
| [[F06-03 Перевод плана плагина и примера]] | перевести `Docs/Tasks/` этого репозитория и `examples/guess-number` на иерархию командой `migrate`. |
| [[F07-01 Дефекты из саморевью]] | исправить дефекты скрипта и хуков, найденные при саморевью и подтверждённые проверкой. |
| [[F08-01 Дефекты из код-ревью]] | исправить все дефекты, найденные код-ревью плагина: скрипт `tasks.mjs`, хуки, скилы, шаблоны. |
