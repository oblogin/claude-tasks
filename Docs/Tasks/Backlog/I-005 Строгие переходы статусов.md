# I-005 Строгие переходы статусов

> **Что:** `tasks.mjs set` проверяет переходы по спецификации (draft → ready → in-progress → review → done; review → in-progress; in-progress → ready; любой → cancelled) и отказывает в остальных без `--force`.
> **Зачем:** сейчас можно, например, поставить `done` задаче из `draft`, минуя работу и журнал; строгие переходы ловят такие ошибки агентов.

Найдено при саморевью ([[F07-01 Дефекты из саморевью]]). Требует решения: строгость мешает законным случаям (переоткрыть `done` для исправления), поэтому нужен `--force` и понятное сообщение.
