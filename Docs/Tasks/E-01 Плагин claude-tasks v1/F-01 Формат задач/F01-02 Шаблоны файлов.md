# F01-02 Шаблоны файлов

> **Что:** сделать шаблоны для каждого типа: epic, feature, task, research, bug, idea, adr.
> **Зачем:** команды и агенты создают файлы из шаблонов, а не по памяти — формат не расползается.
> **Готово, когда:** на каждый тип есть шаблон, и файл, созданный по нему, проходит проверку формата.

## Критерии готовности

- [x] Шаблоны лежат в плагине (`plugin/templates/`); копирование в проект — забота `init` ([[F04-01 Команда init]])
- [x] В каждом шаблоне — frontmatter, «Коротко» и разделы по спецификации
- [x] Внутри шаблонов — короткие подсказки, что писать в разделе (удаляются при заполнении)

## Детали

Шаблоны должны открываться и в Obsidian как обычные заметки — без синтаксиса плагина Templater.

## Проверка

1. Создать по файлу каждого типа из шаблона, прогнать проверку формата (F-03, когда будет готова; до этого — вручную по `plugin/skills/format/SKILL.md`).
