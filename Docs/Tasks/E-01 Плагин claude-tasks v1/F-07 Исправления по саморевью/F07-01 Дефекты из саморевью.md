# F07-01 Дефекты из саморевью

> **Что:** исправить дефекты скрипта и хуков, найденные при саморевью и подтверждённые проверкой.
> **Зачем:** они тихо портят план: теряются вложения, хук трогает чужой план, флаги в другом порядке ломают команды.
> **Готово, когда:** каждый дефект воспроизводится тестом до исправления и не воспроизводится после.

## Воспроизведение

1. `tasks.mjs show --json F01-01` → «Задача «undefined» не найдена»: булев флаг `--json` забирает следующий аргумент как значение.
2. `move F-01 --to E-02` при картинке `схема.png` в папке фичи → картинка остаётся в старой папке, старая папка не удаляется (переносятся только `.md`).
3. Хук `post-tool-use` при правке `Docs/Tasks/…` **другого** проекта пересобирает доску и «присваивает» задачи текущего плана (проверка пути — только по подстроке `Docs/Tasks`).
4. Хуки нескольких параллельных сессий пишут один `sessions.json` по схеме «прочитал-изменил-записал» — одновременные записи теряют владение задачей.
5. Спецификация (разделы 7 и 9) и блок `CLAUDE.md` велят создавать файл из шаблона вручную — при иерархии (ID внутри фичи, папка родителя) это легко сделать неправильно; правильный путь — `tasks.mjs new` / команды.
6. Два файла с одинаковым именем в разных папках молча перекрывают друг друга в разборе ссылок.

**Ожидалось:** флаги в любом порядке; вложения переезжают вместе с фичей; хук реагирует только на свой план; владение не теряется; агентам велено создавать файлы скриптом; дубли имён — ошибка проверки.

## Критерии готовности

- [x] Булевы флаги (`--json`, `--stdout`, `--force`, `--dry-run`, `--claude-md`, `--obsidian`, `--gitignore`) не забирают следующий аргумент
- [x] `move` фичи переносит папку целиком, вместе с вложениями
- [x] Хук реагирует только на файлы внутри плана текущего проекта
- [x] Состояние хуков — отдельный файл на сессию, без гонки
- [x] Спецификация и блок `CLAUDE.md`: новые элементы — через `tasks.mjs new` или команды
- [x] Проверка находит дубли имён файлов
- [x] На каждый пункт — тест; все тесты зелёные

## Проверка

1. `node --test plugin/scripts/test/*.test.mjs`.
2. `tasks.mjs show --json F01-01` — карточка задачи.
