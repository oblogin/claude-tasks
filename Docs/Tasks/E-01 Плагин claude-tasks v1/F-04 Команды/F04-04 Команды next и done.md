# F04-04 Команды next и done

> **Что:** `next` находит следующую готовую задачу и берёт её в работу; `done` закрывает задачу и записывает итог.
> **Зачем:** основной рабочий цикл: «возьми следующую» → работа → «закрой».
> **Готово, когда:** цикл next → done проходит на тестовом проекте, статусы и журнал обновляются сами.

## Критерии готовности

- [x] `next` берёт кандидатов у скрипта, показывает «Коротко» выбранной и 1–2 альтернативы, ставит `in-progress`
- [x] `next <ID>` берёт конкретную задачу; если зависимости не закрыты — предупреждает
- [x] `next --role <роль>` фильтрует по роли
- [x] `done` сверяет критерии готовности; невыполненные пункты — явно, с причиной
- [x] `done` пишет запись в «Журнал», ставит `done` (или `review`) и обновляет доску
- [x] `done` показывает задачи, которые разблокировались, и спрашивает, нужен ли `replan`
