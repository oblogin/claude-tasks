# F-06 Иерархия плана

> **Что:** план раскладывается по вложенным папкам «эпик → фича → задачи», а номер задачи — внутри фичи: `F07-03`.
> **Зачем:** при сотнях задач плоская папка и сквозные номера (`T-5987`) превращаются в свалку; по номеру не видно, к какой фиче относится задача.
> **Готово, когда:** формат, скрипт и команды работают с иерархией, план плагина и пример переведены, проверка чистая.

## Входит

- Раскладка: `E-01 Название/E-01 Название.md`, внутри — `F-01 Название/F-01 Название.md`, внутри — задачи `F01-01 Название.md`. `Backlog/` и `Adr/` — как были.
- ID: эпики `E-01`, фичи `F-01` — сквозные; задачи (task, research, bug) — `F<номер фичи>-<два знака>`, нумерация внутри фичи.
- Проверка: файл лежит в папке своего родителя, ID задачи совпадает с номером фичи.
- `move` — перенос задачи в другую фичу (новый ID, правка всех ссылок) и фичи в другой эпик (ID не меняются); `migrate` — перевод плоского плана.
- Перевод плана плагина и примера `examples/guess-number`.

## Не входит

- Архив закрытых эпиков — с иерархией не нужен: закрытый эпик сворачивается одной папкой.

## Принятые решения

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Вариант структуры | Вложенные папки + номер задачи внутри фичи (выбор пользователя из трёх вариантов). |
| 2 | Ширина номера задачи | Два знака: до 99 задач в фиче; больше — фичу нужно разбить. |
| 3 | Перенос задачи в другую фичу | Меняет ID; старый ID — в журнале задачи. Перенос фичи в другой эпик ID не меняет. |
