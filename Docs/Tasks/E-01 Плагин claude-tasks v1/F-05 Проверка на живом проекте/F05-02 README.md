> **Что:** README плагина: установка, команды, как устроен план, как подключить свою роль.
> **Зачем:** чтобы через месяц не вспоминать, как этим пользоваться.

## Критерии готовности

- [ ] Основной способ установки в README — глобальный (`--scope user`); `--scope local` описан как установка только для папки, где выполнена команда, без подпапок (найдено в [[F05-01 Полный цикл на тестовом проекте]])
- [ ] В README есть подсказка: `Unknown command: /task:…` в папке проекта — плагин не установлен для неё; как проверить (`claude plugin list`) и что сделать
- [ ] По README можно поставить плагин в новый проект и пройти цикл init → create → split → next → done без подсказок
