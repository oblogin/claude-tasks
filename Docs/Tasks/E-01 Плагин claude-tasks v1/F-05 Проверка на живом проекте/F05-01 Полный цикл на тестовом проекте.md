# F05-01 Полный цикл на тестовом проекте

> **Что:** на маленькой тестовой игре пройти init → create эпика MVP → split → несколько next/done → replan → idea.
> **Зачем:** проверить систему в реальной работе, в том числе роли геймдизайнера и программиста.
> **Готово, когда:** цикл пройден, план открывается в Obsidian с рабочим графом, найденные проблемы заведены задачами.

## Критерии готовности

- [ ] Эпик MVP разбит минимум на 3 фичи и 10 задач двух и более ролей
- [ ] Минимум 3 задачи закрыты через `done`, минимум один `replan` изменил будущую задачу
- [ ] Статусы всех задач на доске совпадают с реальным состоянием работы — ни одна не «забыта» в `in-progress`
- [ ] Граф в Obsidian показывает связи эпик/фича/задача и зависимости
- [ ] Каждую задачу можно понять по «Коротко» за несколько секунд — проверено человеком
- [ ] Живой диалог `/task:create` проверен человеком: вопросы по одному, без лишних (перенесено из [[F04-02 Команда create]])
