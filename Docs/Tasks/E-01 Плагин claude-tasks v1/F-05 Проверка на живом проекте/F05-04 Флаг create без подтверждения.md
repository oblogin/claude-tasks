# F05-04 Флаг create без подтверждения

> **Что:** флаг `--yes` (`-y`) у `/task:create` — задача записывается сразу, без показа черновика и вопроса «записывать?».
> **Зачем:** когда пользователь уверен в формулировке, лишний шаг подтверждения только мешает.
> **Готово, когда:** с `--yes` файл создаётся без вопроса о записи, без флага — черновик целиком и выбор «записать / уточнить».

## Критерии готовности

- [x] Без флага: черновик показан целиком, затем вопрос с вариантами «Записать» и «Уточнить»; «Уточнить» — правки и снова черновик; отказ — план не меняется
- [x] С `--yes` или `-y` (в любом месте аргументов): вопрос о записи не задаётся, файл записывается сразу; в итоге показано записанное целиком
- [x] С `--yes` уточняющие вопросы задаются, только если без ответа задачу не написать (непонятно «что» или куда её поставить); остальное агент решает сам
- [x] Флаг описан в `argument-hint` скила, в `/task:help` и в README
- [x] Прогон `claude -p` (Sonnet) в `examples/guess-number` с `--yes`: файл создан без вопроса «записывать?», `check` 0/0; тестовые файлы удалены

## Детали

- Скил: `plugin/skills/create/SKILL.md`; правило «до "да" план не меняется» из [[F05-03 create пишет файл до подтверждения]] остаётся поведением по умолчанию.
- Флаг — часть `$ARGUMENTS`; из текста запроса его убрать.
- Справка `/task:help` строится из самих скилов (`HELP_ORDER` в `tasks.mjs`) — проверить, что флаг в ней виден.
- Поднять `version` плагина и обновить глобальную установку.
