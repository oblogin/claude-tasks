# F03-01 Скрипт проверки графа

> **Что:** Node-скрипт без зависимостей: читает все файлы `Docs/Tasks/`, строит граф и сообщает об ошибках.
> **Зачем:** агенты правят план вручную — нужен детерминированный сторож, который ловит циклы и битые ссылки.
> **Готово, когда:** на намеренно сломанном плане скрипт находит каждую ошибку и возвращает ненулевой код.

## Критерии готовности

- [x] Разбор frontmatter (подмножество YAML, которое использует формат)
- [x] Ссылки внутри `кода` и блоков кода не проверяются (это примеры, а не связи)
- [x] Правила проверки — по спецификации `plugin/skills/format/SKILL.md`, разделы 5–11; за основу можно взять черновую проверку из журнала [[F01-01 Спецификация формата]]
- [x] Ошибки: цикл, ссылка на несуществующий файл, дубль ID, неизвестный статус/тип, нет `parent` у задачи/фичи
- [x] Предупреждения: пустой блок «Коротко», `ready`-задача без критериев готовности
- [x] Предупреждения о статусах: `done` с неотмеченными критериями без пояснения; `done`/`review` без записи в «Журнале»; `in-progress` при незакрытых `depends_on`; больше одной `in-progress` задачи у одной роли
- [x] Вывод понятен человеку и агенту; есть режим JSON для команд
- [x] Тесты на наборе примеров (корректный и сломанные планы)

## Проверка

1. Прогнать на `Docs/Tasks/` этого репозитория — ошибок нет.
2. Прогнать на тестовых сломанных планах — каждая ошибка найдена.
