# F-04 Команды

> **Что:** команды, через которые человек управляет планом и агентами: `/task:help`, `init`, `create`, `split`, `next`, `done`, `replan`, `idea`, `board`.
> **Зачем:** это и есть рабочий интерфейс системы — «создай задачу», «возьми следующую», «закрой и пересмотри план».
> **Готово, когда:** каждая команда работает на тестовом проекте и соблюдает формат F-01.

## Сценарии

- **Создать задачу:** вызываю `create` → агент задаёт вопросы, пока не станет ясно, что нужно → предлагает задачу (или несколько) с местом в графе → после подтверждения пишет файлы.
- **Взять следующую:** `next` → агент берёт кандидатов у скрипта F-03, выбирает по приоритету, показывает «Коротко» и начинает работу.
- **Закрыть:** `done` → сверка критериев, запись итога в «Журнал», предложение правок зависимых задач.

## Принятые решения

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Самостоятельность агента | Агентом управляет человек: одна команда — одна задача, без автоматического перехода к следующей. |
| 2 | Правки будущих задач | Агент только предлагает; изменения пишутся после подтверждения. |
| 3 | Имена команд | Префикс плагина обязателен: `/task:<команда>` ([[ADR-001 Устройство плагина]]). |
