# F-02 Каркас плагина

> **Что:** минимальный плагин Claude Code в этом репозитории, который можно установить локально и увидеть в нём хотя бы одну команду.
> **Зачем:** все остальные фичи кладут свои скилы и команды внутрь этого каркаса.
> **Готово, когда:** плагин устанавливается в тестовый проект, пустая команда вызывается и отвечает.

## Входит

- Исследование механики плагинов Claude Code (скилы vs команды, имена, установка на Windows, запуск скриптов из плагина).
- Манифест плагина, структура папок, локальная установка.

## Не входит

- Сами команды — F-04.
