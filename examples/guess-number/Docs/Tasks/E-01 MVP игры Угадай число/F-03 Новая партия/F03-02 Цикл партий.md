# F03-02 Цикл партий

> **Что:** после победы игра задаёт вопрос «сыграем ещё?» и по ответу начинает новую партию с новым числом или прощается и выходит.
> **Зачем:** можно играть подряд, не перезапуская программу.
> **Готово, когда:** прогон «партия → да → партия → нет» проходит до прощания с кодом выхода 0, тесты разбора ответа зелёные.

## Критерии готовности

- [ ] Тексты раздела «Новая партия» перенесены в `src/messages.js` с теми же ключами
- [ ] Разбор ответа в `src/input.js` (`parseAnswer` → `yes` / `no` / `unknown`) покрыт тестами на все варианты из `Тексты.md`, регистр, пробелы и пустой ответ
- [ ] «Да» начинает новую партию: число загадано заново, счётчик попыток с нуля
- [ ] «Нет» печатает прощание и завершает игру с кодом 0; непонятный ответ обрабатывается как решено в `Тексты.md`
- [ ] Ctrl+C или конец ввода на вопросе «ещё?» завершают игру без трассировки стека
- [ ] `npm test` зелёный

## Детали

- Правила ответа — [[F03-01 Вопрос о новой партии]]; консоль — `src/main.js` из [[F01-05 Консольная партия]].
- Разбор ответа — чистая функция без ввода-вывода, как `parseGuess`.
- С `GUESS_SECRET` все партии получают одно и то же число — это нормально для проверки; без него числа должны отличаться (по ADR — может ли повториться).

## Проверка

1. `npm test` → зелёный.
2. `$env:GUESS_SECRET=42; "42`nда`n42`nнет" | npm start` → две победы, между ними «новая партия», в конце прощание; код выхода 0.
3. `npm start`, сыграть две партии руками — загаданные числа разные (без `GUESS_SECRET`).
