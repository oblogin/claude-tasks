# F01-05 Консольная партия

> **Что:** `npm start` проводит одну партию в терминале: приветствие, ввод догадок, подсказки, победа с числом попыток.
> **Зачем:** игру впервые можно пройти руками.
> **Готово, когда:** партия проходится до победы, все тексты берутся из `src/messages.js` и совпадают с разделом «Партия» `Тексты.md`.

## Критерии готовности

- [ ] `src/messages.js` содержит все строки раздела «Партия» из `Docs/Design/Тексты.md` с теми же ключами
- [ ] Склонение «попытка / попытки / попыток» — функцией в `src/messages.js`, тест на 1, 2, 5, 11, 21, 22, 25
- [ ] `npm start` показывает приветствие, на каждую догадку — подсказку, при угадывании — сообщение о победе с числом попыток, затем выход с кодом 0
- [ ] Ctrl+C или конец ввода завершают игру без трассировки стека
- [ ] Партию можно провести, подав ввод через конвейер (для проверки без человека)
- [ ] `npm test` зелёный

## Детали

- Тексты — [[F01-03 Тексты партии]], логика — `src/game.js` из [[F01-04 Логика партии]].
- Ввод — `node:readline` (`readline/promises`), без зависимостей.
- Разбор ввода здесь минимальный (`Number(line.trim())`); нормальная проверка с сообщениями об ошибках — [[F02-03 Ошибки ввода в игре]]. Вопрос «сыграем ещё?» — [[F03-02 Цикл партий]].
- Чтобы партию можно было прогнать скриптом, в `main.js` предусмотри переменную окружения для фиксированного числа (например, `GUESS_SECRET=42`) — только для проверки, в тексты игры она не попадает.

## Проверка

1. `npm test` → зелёный.
2. `$env:GUESS_SECRET=42; "50`n25`n42" | npm start` → «меньше», «больше», победа за 3 попытки; код выхода 0.
3. `npm start`, сыграть руками до победы; повторить и нажать Ctrl+C посреди партии — выход без ошибки.
