# E-01 MVP игры Угадай число

> **Что:** консольная игра на Node.js без зависимостей: компьютер загадывает число, игрок угадывает по подсказкам «больше / меньше».
> **Зачем:** маленькая, но настоящая игра, на которой проверяем плагин задач.
> **Готово, когда:** игра запускается командой `npm start`, партию можно пройти до победы и сразу начать новую.

## Цель

Играбельный минимум для одного игрока в терминале. Ограничения:

- только Node.js и его стандартная библиотека (`readline` и т. п.) — никаких npm-зависимостей;
- запуск — `npm start` из корня проекта;
- весь интерфейс — на русском.

## MVP

- Компьютер загадывает случайное целое число в заданном диапазоне.
- Игрок вводит догадки; игра отвечает «больше» или «меньше», пока число не угадано.
- Игра считает попытки и сообщает их число при победе.
- После победы игра предлагает сыграть ещё: «да» — новая партия с новым числом, «нет» — выход.

## После MVP

- Уровни сложности (диапазон, лимит попыток).
- Рекорды между запусками.
- Конкретные идеи — в `Backlog/`.
