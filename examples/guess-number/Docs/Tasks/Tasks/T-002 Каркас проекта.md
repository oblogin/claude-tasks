# T-002 Каркас проекта

> **Что:** завести `package.json`, точку входа и тестовый прогон без npm-зависимостей.
> **Зачем:** остальным задачам программиста есть куда класть код и тесты.
> **Готово, когда:** `npm start` выводит строку-заглушку и завершается с кодом 0, `npm test` проходит с одним тестом-заглушкой.

## Критерии готовности

- [x] `package.json` без `dependencies` и `devDependencies`, с `"type": "module"` и полем `engines.node`
- [x] `npm start` запускает `src/main.js`, выводит заглушку и завершается с кодом 0
- [x] `npm test` запускает `node --test`, находит `test/*.test.js` и проходит
- [x] `.gitignore` исключает `node_modules/`

## Детали

- Раскладка — как в «Принятых решениях» [[F-01 Партия до победы]]: `src/main.js`, `src/game.js`, `src/input.js`, `src/messages.js`, тесты в `test/`. В этой задаче создаются только `src/main.js` и `test/smoke.test.js`; остальные модули появятся в своих задачах.
- Тесты — только `node:test` и `node:assert/strict`.
- Версия Node в `engines` — та, что стоит у разработчика (`node --version`), не ниже 20: в ней `node --test` сам находит тесты.
- `.gitignore` уже есть в корне — дополнить, если нужно.

## Проверка

1. `npm start` → выводится заглушка, `echo $LASTEXITCODE` (PowerShell) → `0`.
2. `npm test` → `pass 1`, `fail 0`.
3. В `package.json` нет разделов зависимостей.
