# T-012 Оценка в сообщении о победе

> **Что:** после сообщения о победе игра печатает оценку по шкале из раздела «Оценка» `Тексты.md`.
> **Зачем:** у игрока появляется цель — угадать быстрее.
> **Готово, когда:** функция выбора ступени покрыта тестами на все пороги, и при победе в терминале видна нужная оценка.

## Критерии готовности

- [ ] Тексты раздела «Оценка» перенесены в `src/messages.js` с теми же ключами
- [ ] Функция «число попыток → ступень» проверена тестами на каждой границе порогов (порог и порог + 1) и на 1 попытке
- [ ] Пороги лежат в одном месте (таблица-константа), чтобы [[T-013 Плейтест и баланс]] мог их поменять одной правкой
- [ ] Оценка выводится при каждой победе, в том числе во второй и следующих партиях
- [ ] `npm test` зелёный

## Детали

- Шкала — [[T-009 Шкала оценки по попыткам]]; сообщение о победе — [[T-005 Консольная партия]].
- Выбор ступени — чистая функция (в `src/game.js` или `src/messages.js` — на выбор, запиши в журнал).

## Проверка

1. `npm test` → зелёный.
2. `$env:GUESS_SECRET=42; "42" | npm start` → победа за 1 попытку и оценка для первой попытки.
3. `$env:GUESS_SECRET=42; "50`n25`n37`n43`n40`n41`n42" | npm start` → победа за 7 попыток и оценка ступени, в которую попадает 7 (пример для диапазона 1–100; если ADR выбрал другой — подбери догадки под него).
