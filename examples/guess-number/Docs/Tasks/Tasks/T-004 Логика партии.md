# T-004 Логика партии

> **Что:** модуль `src/game.js`, который загадывает число в диапазоне из ADR, сравнивает догадки и считает попытки.
> **Зачем:** правила игры проверяются тестами отдельно от консоли.
> **Готово, когда:** тесты `test/game.test.js` на сравнение, подсчёт попыток и границы диапазона зелёные.

## Критерии готовности

- [ ] Загаданное число всегда целое и лежит в диапазоне из ADR, включая обе границы (тест с подменённым генератором на 0 и на почти 1)
- [ ] Догадка меньше загаданного → результат «больше», больше → «меньше», равна → «победа»
- [ ] Счётчик попыток растёт на каждую догадку по правилам ADR и доступен после победы
- [ ] Модуль не читает ввод и не печатает: никаких `console`, `readline`, строк интерфейса
- [ ] `npm test` зелёный

## Детали

- Правила — ADR из [[T-001 Правила и диапазон]]. Здесь догадка уже число: разбор строки — [[T-007 Разбор догадки]].
- Генератор случайных чисел передаётся параметром (по умолчанию `Math.random`), чтобы тесты были детерминированными. Примерная форма: `createGame({ min, max, random })` → объект с `guess(n)` → `'higher' | 'lower' | 'win'` и `attempts`. Форму можно поменять — запиши решение в журнал.
- Результаты — коды, а не тексты: тексты подставит `src/messages.js`.

## Проверка

1. `npm test` → все тесты `game.test.js` проходят.
2. Поиск по `src/game.js`: нет `console` и `readline`.
