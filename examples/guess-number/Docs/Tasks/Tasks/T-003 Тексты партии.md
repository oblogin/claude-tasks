# T-003 Тексты партии

> **Что:** написать все сообщения одной партии — от приветствия до победы — в документе `Docs/Design/Тексты.md`.
> **Зачем:** программист переносит готовые строки, а не придумывает их сам.
> **Готово, когда:** в `Тексты.md` есть раздел «Партия» со всеми сообщениями из списка ниже, у каждого — ключ и финальный текст.

## Критерии готовности

- [x] Создан `Docs/Design/Тексты.md` с разделом «Партия»
- [x] Есть тексты: приветствие с правилами и диапазоном, приглашение ввести число, подсказка «загаданное больше», подсказка «загаданное меньше», победа с числом попыток
- [x] У каждого сообщения есть латинский ключ (`greeting`, `prompt`, `hintHigher`, `hintLower`, `win`) — по нему программист находит строку
- [x] Подстановки обозначены явно (`{min}`, `{max}`, `{attempts}`), для числа попыток даны все три формы: 1 попытка, 2 попытки, 5 попыток
- [x] Подсказки однозначны: из текста ясно, что больше — загаданное число, а не догадка игрока

## Детали

- Диапазон и правила — из ADR задачи [[T-001 Правила и диапазон]].
- Тон — дружелюбный, коротко, одна строка на сообщение; всё на русском.
- Документ дальше пополняют [[T-006 Тексты ошибок ввода]], [[T-008 Вопрос о новой партии]] и [[T-009 Шкала оценки по попыткам]] — оставь место под их разделы («Ошибки ввода», «Новая партия», «Оценка»).
- Формат записи — таблица «Ключ · Когда показывается · Текст».

## Проверка

1. Открыть `Docs/Design/Тексты.md` — все пять ключей есть, у каждого финальный текст без «TODO».
2. Подставить в `win` значения 1, 3, 5, 21 — все фразы грамматически верны.
