# T-006 Тексты ошибок ввода

> **Что:** дописать в `Docs/Design/Тексты.md` раздел «Ошибки ввода» — что игра отвечает на каждый вид неверного ввода.
> **Зачем:** игрок сразу понимает, что ввёл не так, и не теряет попытку зря.
> **Готово, когда:** для каждого вида ошибки из списка ниже есть ключ и финальный текст, и каждый текст говорит, что ввести вместо этого.

## Критерии готовности

- [ ] Раздел «Ошибки ввода» есть в `Docs/Design/Тексты.md`
- [ ] Тексты для видов ошибок: пустая строка (`errorEmpty`), не число (`errorNotNumber`), дробное число (`errorNotInteger`), вне диапазона (`errorOutOfRange`)
- [ ] Каждый текст подсказывает правильный ввод; `errorOutOfRange` называет границы через `{min}` и `{max}`
- [ ] Если по ADR повтор уже названного числа — отдельный случай, для него тоже есть текст (`errorRepeat`); если нет — это записано в журнале

## Детали

- Что считается ошибкой и засчитывается ли попытка — ADR из [[T-001 Правила и диапазон]].
- Стиль и формат таблицы — как в разделе «Партия» из [[T-003 Тексты партии]].
- Программист сопоставит тексты кодам ошибок из [[T-007 Разбор догадки]] по ключам — ключи не меняй без записи в журнале.

## Проверка

1. Открыть `Docs/Design/Тексты.md` → раздел «Ошибки ввода»: все ключи на месте, тексты финальные.
2. Прочитать каждый текст вслух с примером ввода (`""`, `abc`, `3.5`, `1000`) — по тексту понятно, что ввести.
