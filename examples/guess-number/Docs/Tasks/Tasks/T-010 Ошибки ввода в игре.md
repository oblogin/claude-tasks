# T-010 Ошибки ввода в игре

> **Что:** консольная партия разбирает ввод через `src/input.js` и на ошибку печатает текст из раздела «Ошибки ввода».
> **Зачем:** опечатка не ломает партию и не тратит попытку.
> **Готово, когда:** прогон с неверным вводом показывает нужные сообщения, а число попыток при победе считает только корректные догадки.

## Критерии готовности

- [ ] Тексты раздела «Ошибки ввода» из `Docs/Design/Тексты.md` перенесены в `src/messages.js` с теми же ключами
- [ ] Каждый код ошибки `parseGuess` приводит к своему сообщению, после которого игра снова просит число
- [ ] Неверный ввод не увеличивает счётчик попыток (или увеличивает — строго по ADR)
- [ ] Временный разбор `Number(line.trim())` из [[T-005 Консольная партия]] удалён
- [ ] `npm test` зелёный

## Детали

- Разбор — [[T-007 Разбор догадки]], тексты — [[T-006 Тексты ошибок ввода]], правило о попытках — ADR из [[T-001 Правила и диапазон]].
- Тест на соответствие «каждый код ошибки имеет текст в `messages.js`» — дешёвая защита от рассинхрона; добавь.

## Проверка

1. `npm test` → зелёный.
2. `$env:GUESS_SECRET=42; "`nabc`n3.5`n1000`n42" | npm start` → четыре разных сообщения об ошибке, затем победа за 1 попытку (если ADR не засчитывает ошибки).
