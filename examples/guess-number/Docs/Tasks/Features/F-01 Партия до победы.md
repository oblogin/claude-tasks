# F-01 Партия до победы

> **Что:** по `npm start` компьютер загадывает число, игрок вводит догадки и получает подсказки «больше / меньше», пока не угадает.
> **Зачем:** это ядро игры — без него остальных фич нет.
> **Готово, когда:** партию можно пройти в терминале от приветствия до сообщения о победе с числом попыток, `npm test` зелёный.

## Входит

- Правила партии и диапазон чисел — решение в ADR.
- Каркас проекта: `package.json`, `npm start`, `npm test` на `node:test`, без зависимостей.
- Тексты партии: приветствие, приглашение ввести число, подсказки, победа.
- Логика партии (загадать число, сравнить догадку, посчитать попытки) — отдельно от консоли и покрыта тестами.
- Консольный цикл одной партии на `readline`.

## Не входит

- Разбор неверного ввода и сообщения об ошибках — [[F-02 Защита от неверного ввода]].
- Вопрос «сыграем ещё?» — [[F-03 Новая партия]].
- Оценка результата по числу попыток — [[F-04 Оценка результата]].
- Уровни сложности и лимит попыток — после MVP.

## Принятые решения

| # | Вопрос | Решение |
|---|--------|---------|
| 1 | Где живут тексты | Геймдизайнер ведёт `Docs/Design/Тексты.md`, программист переносит их в `src/messages.js`; строк в других модулях нет |
| 2 | Раскладка кода | `src/game.js` — логика, `src/input.js` — разбор ввода, `src/messages.js` — тексты, `src/main.js` — консоль; тесты в `test/*.test.js` |
