# Шаблоны

По одному шаблону на тип: `epic`, `feature`, `task`, `research`, `bug`, `idea`, `adr`. Имя файла шаблона = тип. Язык — только русский.

## Подстановки

| Метка | Чем заменить |
|-------|-------------|
| `{{id}}` | ID по правилам формата: `T-042`, `F-07`, `E-01`, `I-003`, `ADR-002` |
| `{{title}}` | Короткое название (2–6 слов) |
| `{{date}}` | Дата создания `YYYY-MM-DD` |
| `{{role}}` | Кто делает задачу — свободная метка (`programmer`, `gamedesigner`, `artist`, имя агента…). Если исполнитель не важен — строку `role` удалить |
| `{{priority}}` | `must` \| `should` \| `could` |
| `{{size}}` | `XS` \| `S` \| `M` \| `L` |
| `{{parent}}` | Полное имя родителя без скобок: `F-07 Прыжок` |
| `{{task}}` | (adr) полное имя research-задачи |

Во frontmatter метки стоят в кавычках, чтобы шаблон оставался корректным YAML: `id: "{{id}}"`. При заполнении кавычки вокруг простого значения убираются (`id: T-042`), а у ссылок остаются (`parent: "[[F-07 Прыжок]]"`).

## Подсказки

Подсказки — HTML-комментарии `<!-- … -->`: в режиме чтения Obsidian их не видно. При заполнении все комментарии удаляются; раздел, в который нечего писать, можно убрать, кроме «Коротко» и «Журнала».

Файл сохраняется как `<Папка типа>/{{id}} {{title}}.md`, заголовок `# {{id}} {{title}}` совпадает с именем файла.
