# Шаблоны

По одному шаблону на тип: `epic`, `feature`, `task`, `research`, `bug`, `idea`, `adr`. Имя файла шаблона = тип. Язык — только русский.

## Подстановки

| Метка | Чем заменить |
|-------|-------------|
| `{{id}}` | ID по правилам формата: `E-01`, `F-07`, задача `F07-03`, `I-003`, `ADR-002` — выдаёт `tasks.mjs new` |
| `{{title}}` | Короткое название (2–6 слов) |
| `{{date}}` | Дата создания `YYYY-MM-DD` |
| `{{role}}` | Кто делает задачу — свободная метка (`programmer`, `gamedesigner`, `artist`, имя агента…). Если исполнитель не важен — строку `role` удалить |
| `{{priority}}` | `must` \| `should` \| `could` |
| `{{size}}` | `XS` \| `S` \| `M` \| `L` |
| `{{parent}}` | Полное имя родителя без скобок: `F-07 Прыжок` |
| `{{task}}` | (adr) полное имя research-задачи |

Во frontmatter метки стоят в кавычках, чтобы шаблон оставался корректным YAML: `id: "{{id}}"`. При заполнении кавычки вокруг простого значения убираются (`id: F07-03`), а у ссылок остаются (`parent: "[[F-07 Прыжок]]"`).

## Подсказки

Подсказки — HTML-комментарии `<!-- … -->`: в режиме чтения Obsidian их не видно. При заполнении все комментарии удаляются; раздел, в который нечего писать, можно убрать, кроме «Коротко» и «Журнала». У задачи не в `draft` оставшиеся подсказки `check` показывает предупреждением. Пустой пункт `- [ ]` в «Критериях готовности» — заготовка: критерием он не считается, пока в нём нет текста.

Блок `project/claude-md-block.md` для `CLAUDE.md` проекта: метка `{{plan}}` — путь к плану от корня проекта (`Docs/Tasks` или `docs/Tasks`), подставляет `tasks.mjs init`.

Файл создаёт `tasks.mjs new` в нужном месте иерархии (эпик — своя папка, фича — папка в эпике, задача — в папке фичи; идея — `Backlog/`, ADR — `Adr/`); заголовок `# {{id}} {{title}}` совпадает с именем файла.
