# План задач

Эта папка — план проекта в формате плагина **task** (claude-tasks). Открывается в Obsidian как обычное хранилище, без плагинов.

- [[Board]] — доска: что готово к работе, что в работе, что заблокировано. Генерируется командой `/task:board`, руками не править.
- План — по иерархии: папка эпика `E-01 …` → папки фич `F-03 …` → задачи `F03-01 …`, `F03-02 …`. `Backlog/` — идеи, `Adr/` — принятые решения.
- Формат задач и правила работы с планом — скил плагина `task:format`. Список команд — `/task:help`.

**Главное правило для всех, кто работает с планом:** взял задачу — поставь `in-progress` и запиши в «Журнал»; закончил — отметь критерии, поставь `done` (или `review`, если нужна проверка человеком) и запиши итог. Статус и журнал обновляются сразу, а не потом.
