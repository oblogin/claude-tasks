# /task:board — проверка плана и доска

Скрипт плагина: `node "${CLAUDE_PLUGIN_ROOT}/scripts/tasks.mjs"` (дальше — «скрипт»).

1. `скрипт board --json` — пересобирает `Docs/Tasks/Board.md` и возвращает ошибки, предупреждения и очередь `next`.
2. `скрипт list --status in-progress,review --json` — что сейчас в работе и на проверке.
3. Сводка в чат — коротко, без пересказа всей доски:

```
Доска обновлена. Готово к работе: T-012, T-013 (первая в очереди — T-012 Команда replan).
В работе: T-011 (programmer). На проверке: T-009 — ждёт вашей проверки.
Проверка: ✓ без ошибок.
```

4. **Ошибки и предупреждения** — перечисли с файлом и сутью. Для каждой предложи исправление; исправляй только с согласия пользователя (это чужие задачи — раздел 9 скила `task:format`). Типичные:
   - битая ссылка — файл переименован: поправить ссылку на актуальное имя;
   - пустой «Коротко» / подсказки `<!-- … -->` — задачу недописали после создания;
   - `in-progress` при незакрытых зависимостях, несколько `in-progress` у одной роли — спросить, что из этого актуально;
   - `done` с неотмеченными критериями — отметить выполненные или зачеркнуть снятые с причиной.

   После исправлений — снова `скрипт board`.
5. Если в работе задача без записи в журнале за сегодня — напомни, что статус и журнал обновляются сразу.
