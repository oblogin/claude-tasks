# /task:idea — идея в бэклог

Скрипт плагина: `node "${CLAUDE_PLUGIN_ROOT}/scripts/tasks.mjs"` (дальше — «скрипт»). Идея: `$ARGUMENTS`.

Идея — мысль «на потом»: она не в плане, ничего не блокирует и не имеет зависимостей. Цель команды — записать быстро, **без вопросов**.

1. Аргументов нет — спроси одной фразой: «Какую идею записать?» Это единственный допустимый вопрос.
2. Проверь, нет ли такой же идеи или задачи: `скрипт list --json` (по названиям и «Что»). Есть — скажи, где она, и не создавай дубль.
3. Придумай короткое название (2–6 слов) и создай файл: `скрипт new idea --title "<название>" --json`.
4. В созданный файл впиши «Коротко» и удали подсказки `<!-- … -->`:
   - **Что:** идея одним предложением — словами пользователя, чуть причёсанными;
   - **Зачем:** что она может дать — из слов пользователя; если он не сказал — одно разумное предположение, отмеченное «(предположение)».
   Подробности, если пользователь их дал, — одной-двумя строками под «Коротко».
5. `скрипт check` и `скрипт board`.
6. Ответ одной строкой: «Записал I-007 Кооператив в бэклог.» Когда идею захотят сделать — `/task:create` на её основе.
